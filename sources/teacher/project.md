### **学习目标**

项目拆解阶段重点不是记代码，而是从业务角度理解项目。

需要达到：

- 理解项目整体业务逻辑
- 熟悉完整业务流程
- 看懂核心合约与后端模块职责
- 理解前端、后端、合约之间的数据流转
- 能够独立讲解项目架构和实现思路

### **学习重点**

#### **合约部分**

重点关注：

- 项目解决什么问题
- 核心业务流程是什么
- 用户操作对应哪些合约方法
- 合约之间如何协作
- 资金如何流转

#### **后端部分**

重点关注：

- 项目整体结构
- 各模块职责
- 链上数据同步流程
- 事件监听与数据入库
- API 服务设计
- 后端与合约的交互方式

### **最终要求**

完成学习后，需要能够：

- 画出项目整体架构图
- 讲清核心业务流程
- 说明主要模块职责
- 从业务角度分析代码实现
- 快速理解同类型 Web3 项目结构
